Ceiling Hub Premium Website

A modern, premium frontend for Ceiling Hub Pvt Ltd, designed to showcase ceiling systems, insulation materials, gypsum products, and construction solutions for commercial and residential projects.

---

🚀 Live Demo

"View Live Website" (https://ceilinghub.in)

---

🧠 Overview

This project is a high-end product showcase website built with a focus on:

- Premium UI/UX (Apple-level aesthetics)
- Conversion-driven product pages
- Smooth animations and interactions
- Scalable product architecture
- B2B-focused design (contractors, architects, builders)

---

🛠 Tech Stack

- Frontend: React (Vite)
- Styling: Tailwind CSS
- Routing: React Router DOM
- Animations: Framer Motion
- Icons: React Icons
- Deployment: Vercel

---

📁 Project Structure

src/

│   ├── ProductPage.jsx

│

├── config/            # Contact config
├── hooks/             # Custom hooks
└── main.jsx

📦 Installation

Clone the repository:

git clone https://github.com/retarduser404/ceiling-hub-premium.git
cd ceiling-hub-premium

Install dependencies:

npm install

Run development server:

npm run dev

---

🚀 Build

npm run build
